# RAG 首批评测用例

整理日期：2026-09-15。

状态：5 条基线用例均已收到本轮结果，均符合预设的用户侧行为标准。T01、T03、T04 检索与生成回答通过；T02、T05 在检索无结果后直接提示资料不足。T02 未覆盖的“模型收到相关却不足的资料”分支仍待补测。此前演示结果不作为本轮测试记录。

## 场景与范围

暂定用户是希望快速理解 AI 基础概念的初学者。用户反馈：网上资料复杂、分散，不容易快速找到需要的解释。这是目前的个人需求描述，尚未经过其他用户验证。

本轮只评测“根据知识库回答”的版本：资料能够支持时回答并引用；依据不足时说明不足。允许模型用自身知识补充是后续需求，不纳入本轮，也不自动把生成内容写回知识库。

## 当前测试条件

- 入口文件：`rag.py`。
- 知识库：`knowledge_base.txt`，4 个非空段落，分别介绍 RAG、Agent、AI 产品评估和 API。
- 向量模型：`BAAI/bge-small-zh-v1.5`。
- 切分参数：`MAX_CHUNK_SIZE=100`，`CHUNK_OVERLAP=20`。
- 检索参数：`TOP_K=3`，`MINIMUM_SCORE=0.55`。
- 生成模型配置：`LLM_MODEL_NAME="gpt-5.5"`。这是代码配置名称，不是对接口服务商实际后端模型的独立验证。
- 运行前核对上述条件；若有变化，在结果记录中注明。不要记录密钥或带凭证的接口地址。

这些用例是初始开发用例，不是独立留出验证集。不得用 5 道题的结果推断真实场景总体表现。

## T01：单段资料足够

- 用户问题：RAG 是怎么工作的？
- 预期支持资料：第 1 段。
- 答案必须包含：根据问题检索相关资料；大模型结合检索到的资料生成回答。
- 可选补充：引入资料可以减少仅依赖模型内部知识回答造成的错误。
- 不应出现：完全消除幻觉、保证所有回答正确等承诺。
- 回答通过标准：核心流程正确，引用第 1 段，且无上述过度承诺；不要求逐字一致。

## T02：主题相关，但依据不足

- 用户问题：RAG 的检索相似度阈值应该设置为多少？
- 资料情况：第 1 段与主题相关，但知识库没有阈值设置方法或推荐数值；没有足以回答本题的段落。
- 预期行为：明确说明当前资料不足以给出具体阈值或设置方法。
- 不应出现：编造阈值；把程序配置值当作通用标准；只重复 RAG 定义而不说明不足。
- 回答通过标准：说明依据不足，不提供无依据的设置建议。没有检索结果时直接提示资料不足也可通过回答检查，但应如实记录实际检索情况。
- 注意：检索到第 1 段，不等于找到了答案；不能强制要求回复声称“已找到相关资料”。

## T03：需要多段资料

- 用户问题：RAG 和 AI Agent 的工作方式有什么区别？
- 预期支持资料：第 1、2 段。
- 答案必须包含：RAG 检索资料并结合资料生成回答；Agent 围绕目标决策、调用工具，并读取结果判断是否执行下一步。
- 不应出现：只解释其中一方；声称两者互斥或 Agent 绝不能使用检索。
- 回答通过标准：准确比较双方工作方式，引用实际支持比较的第 1、2 段。
- 注意：本轮不要求展开 Agent 与 RAG 的组合架构，避免把课堂补充概念当成知识库已有内容。

## T04：口语表达与语义检索

- 用户问题：这个 AI 助手说话很流畅，是不是就说明它做得不错？还需要检查什么？
- 预期支持资料：第 3 段。
- 答案必须包含：不能仅凭回答流畅判断产品效果；从资料所列评估方面中举出至少三个。
- 允许的评估方面：任务完成率、检索精确率、召回率、错误类型、响应速度、运行成本。
- 不应出现：认定流畅就代表质量好；以泛泛的“系统能正确回答”代替对问题的判断。
- 回答通过标准：判断明确，举例符合资料，引用第 3 段。“准确率”不能在未定义时直接代替“检索精确率”。

## T05：知识库范围之外

- 用户问题：如何计算定积分？
- 预期支持资料：无，4 段资料均不涉及积分。
- 预期行为：说明资料不足；“没有找到足够相关的内容”也是可接受的表达。
- 不应出现：输出积分方法，或把 AI 资料引用为积分回答的依据。
- 回答通过标准：明确说明无法依据当前资料作答，不编造答案和来源。
- 检索预期：无结果。若有无关段落被返回，应记录为误检，即使最终回答正确拒答也不能说检索通过。
- 程序行为检查：若检索结果为空，应直接提示，不发送生成请求；若误检后模型拒答，则分别记录误检和回答表现。

## 如何记录

先保持代码和参数不变，一次运行一道题。保留用户问题、传给模型的参考段落、实际回答或终端提示，以及报错情况。没有结果时不补造提示词、答案或分数。

分开判断：

1. 检索检查：需要的资料是否找齐，是否夹带无关资料。T02 另检查资料相关却不足以支撑回答的情况。
2. 回答检查：是否符合该题预期行为，答案是否有依据，引用是否支持结论。

无法连接接口等程序问题记为“运行失败”，不能当作模型正确拒答。最终答案正确，也不能掩盖前面的误检或漏检。
